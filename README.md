# Python Fundamentals Portfolio

A collection of interactive Python desktop applications built using Tkinter, combining fundamental programming concepts into a single unified portfolio hub.

## Projects Included

1. **Project 1: Basic Calculator**
   - Performs fundamental arithmetic operations with user input handling.

2. **Project 2: Tip & Bill Splitter**
   - Calculates total bill amounts with customizable tips and splits expenses evenly.

3. **Project 3: Unit & Currency Converter**
   - Converts temperature units, distance metrics, and currency rates with memory reference tracking.

4. **Project 4: Interest & Age Calculator**
   - Calculates Simple & Compound Interest alongside a dynamic birth year-based age computation.
